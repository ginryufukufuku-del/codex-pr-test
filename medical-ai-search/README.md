# 医療AI 横断検索アシスタント（試作版）

患者情報（年齢・性別・主訴・現病歴・身体所見・検査/画像所見）を1回入力し、
複数の医療系AI/検索サービスをボタンで選んで同時に開くための試作アプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド不要・外部通信なし）。

1. 患者情報を入力する
2. 検索したいサービスをボタン（チップ）で選択する
3. 「選択したサービスを開く＆コピー」を押す
   - 検索語をURLで渡せるサービスは、検索結果画面が直接開きます
   - それ以外はトップページ/ログイン画面が開き、クエリはクリップボードにコピーされるので貼り付けてください

## 事実確認（重要な制約）

ご要望の「北斗（ホクト）、OpenEvidence、UpToDate、MEDII などに患者情報をAPIで同時送信し、回答をまとめて受け取る」という機能は、**現時点では実現できません**。理由は以下の通りです。

| サービス | 公開API | 備考 |
|---|---|---|
| ホクト (Hokuto) | なし | 日本の医師向け臨床支援アプリ。外部連携APIは非公開。 |
| OpenEvidence | なし | 米国の医師資格認証が必要な会員制サービス。 |
| UpToDate | 検索URLに検索語を渡すことは可能だが、本文閲覧・回答取得のAPIは機関/個人契約者向けのみ。 | 検索結果ページは開ける。 |
| Glass Health | なし（一部ベータ的な機能はあるが一般公開APIではない） | ログインが必要。 |
| Ubie AI問診 | なし | 患者向け症状チェッカー。構造化フォームだが外部API非公開。 |
| MEDII | なし | 希少疾患の専門医相談プラットフォーム。 |
| PubMed | あり（E-utilities、無料） | 文献検索には実際に活用可能。 |

そのため本ツールは「入力の一元化＋ワンクリックでの複数タブ起動＋クリップボードコピー」を行う
**検索ランチャー**として設計しています。将来的に各社が公式APIを公開した場合は、
`SERVICES` 配列（`index.html` 内）にAPI呼び出し処理を追加する形で拡張できます。
