回答を貼り付け NotebookLMを開く
使い方（タップで開く）
  1. 上の緑・青のボタンで、使うAIをタップします（下に、そのAIのバーと、回答メモの欄ができます）。
  2. AIのバーをタップして、AIサイトを開き、質問します。
  3. 回答が出たら、回答の下のコピーマークをタップします。
  4. このアプリのタブに戻り、画面の下の白い枠をタップ →キーボード左上の📋をタップします（貼り付け）。
  5. 下のバーの、そのAIの名前をタップします。回答メモの欄に、出典の見出し付きで入ります。
  6. ほかのAIも、2〜5を繰り返します。
  7. 終わったら、回答メモの欄の文章をコピーして、NotebookLMに貼り付けます（AIごとに別のソース）。

別のAIの回答が入ってしまったときは、そのAIの「リセット」を押して、やり直します。

ショートカット「AI回答コピー」（Safari）を使うと、サイト名が付くので、白い枠に貼り付けるだけで、AIごとに自動で振り分けられます。
