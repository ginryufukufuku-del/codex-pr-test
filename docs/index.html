使い方（タップで開く）
  1. iPadで、このアプリとSafariを左右に並べて開いておくと、行き来せずに使えます。
  2. 患者情報を入れ、使うAIのチップをタップします（AIごとのバーと、回答メモの欄ができます）。
  3. AIのバーをタップして、AIサイトを開き、質問します（質問文は自動でコピーされます）。
  4. 回答が出たら、そのAIのコピーマークをタップします。
  5. このアプリに戻り（または並べた画面で）、そのAIのバーの右の「ペースト」をタップします。出典の見出し付きで入り、バーに✓が付きます。入らないときは、下の回答メモのそのAIの欄を長押し →「ペースト」です。
  6. ほかのAIも、3〜5を繰り返します。
  7. 全部そろったら、回答メモの「全ペースト」を押すと、全AIの回答が1つにまとまってコピーされます。「ジェミニノートブック」で開き、テキストとしてペーストします（AIごとに別のソースにしたいときは、次のとおり）。
  8. 「ペースト」を押した直後は、出典付きの回答がコピーされた状態です。「ジェミニノートブック」で開き、AIごとに別のソースとしてペーストします（あとから取り出すときは、下の回答メモの欄を長押し →「すべてを選択」→「コピー」）。

違う回答が入ったときは、もう一度ペーストすると上書きされます。バーの右の「リセット」で空にもできます。
