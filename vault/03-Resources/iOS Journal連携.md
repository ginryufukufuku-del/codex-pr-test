# iOS Journal連携

iPhoneの音声入力をこのセカンドブレインに取り込むための仕組み。

## 現状の運用方法（確定）

**iPhoneキーボードのマイク機能で、このチャット（Claude Code）に直接話しかける方式**を
正式な運用フローとする。音声→テキスト化→Claude Codeが `00-Journal` 等へ整形、という
流れで、セットアップ不要・動作確認済み・安定している。

## 保留中: iOS Shortcuts自動送信

- `vault/99-Inbox/` : Shortcutsから送る想定の未処理データ受け皿（現在は未使用）
- Shortcuts → GitHub Contents API（PUT）→ `99-Inbox/` にMarkdownをコミットする案
- 一度は送信に成功したが、以後「ネットワーク接続が切れました」エラーが続き
  未解決。本来の目的（ジャーナル→Obsidian管理）には必須ではないため保留。
- セットアップ手順は `docs/ios-journal-sync.md` に記載（保留中の参考資料）。
- 詳細な経緯は [[セカンドブレイン拡張計画]] 参照。

## 制約

- Journalアプリに公開APIが無いため、Shortcuts経由の完全自動化は
  文字起こし後の共有操作が必要（手動実行）。
