# Vault

Obsidian で開くための Vault ルートです。PARA 方式で構成しています。

- `00-Journal/` : デイリーノート（日々のジャーナル）
- `01-Projects/` : 期限・成果物のある進行中プロジェクト
- `02-Areas/` : 継続的に責任を持つ領域
- `03-Resources/` : 後で参照する知識・資料
- `04-Archive/` : 完了・非アクティブになったノート
- `99-Inbox/` : iOS Shortcuts経由で送られた未処理の取り込みノート
  （iPhone Journalアプリの音声記録）

運用ルールはリポジトリルートの `CLAUDE.md` および
`.claude/skills/second-brain/SKILL.md` を参照してください。
