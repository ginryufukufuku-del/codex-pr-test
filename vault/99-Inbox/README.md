# Inbox（未処理の取り込みノート）

iOS Journal アプリの音声記録（文字起こし済みテキスト）が、iOS Shortcuts経由で
自動的にここへ書き込まれます。ファイルはまだ整理されていない「生データ」です。

## ファイル形式

Shortcuts が作成するファイル名: `YYYY-MM-DDTHH-mm-ss.md`

```markdown
---
source: ios-journal
captured: 2026-09-28T21:15:00+09:00
---

（Journalアプリの音声入力を文字起こししたテキストがそのまま入る）
```

## 処理フロー

1. Claude Code（`/second-brain` スキル）がこのフォルダのファイルを検出する。
2. 内容を要約・整理し、対応する日付の `vault/00-Journal/YYYY-MM-DD.md` に
   追記する（複数のInboxファイルが同じ日付なら同じジャーナルにまとめる）。
3. 内容にプロジェクト/領域/参照情報として独立させるべきものがあれば
   `01-Projects` / `02-Areas` / `03-Resources` にノートを作成しリンクする。
4. 処理済みのInboxファイルは削除する（内容はジャーナル側に転記済みのため、
   Inboxに残す必要はない）。

このフォルダにあるファイルは「未処理」を意味するので、空でない場合は
次にClaude Codeを起動したときに処理を促してください。
