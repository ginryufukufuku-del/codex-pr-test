# セカンドブレイン拡張計画

iPhone/iPadの音声入力アプリごとに、それぞれ別のセカンドブレイン連携を作る計画。

## 作りたいもの（2系統）

1. **ジャーナル版セカンドブレイン**
   - 入力元: iPhoneの「ジャーナル」アプリの音声記録
   - 連携方法: iOS Shortcuts → GitHub Contents API → `vault/99-Inbox/` →
     ローカルWhisperで自動文字起こし → `vault/00-Journal/` に整理
   - 状況: 手順書・スクリプトは作成済み（[[iOS Journal連携]]、
     `docs/ios-journal-sync.md`、`scripts/transcribe_inbox.py`）。
     実機でのiOS Shortcuts設定・本番テストは未実施。

2. **メモアプリ版セカンドブレイン**
   - 入力元: iPadの「メモ」アプリの音声記録
   - 連携方法: 未設計（ジャーナル版とは別形式、または別アプリとして
     切り出す想定）
   - 状況: 未着手

## 進め方

- 先に①ジャーナル版を完成させる（iOS Shortcutsの実機設定 → 動作確認）。
- ①が安定してから、②メモアプリ版の設計に着手する。
- 2つは同じ`vault/99-Inbox/`を共有するか、別の受け皿フォルダに分けるかは
  ②の設計時に決める。
