# セカンドブレイン拡張計画

iPhone/iPadの音声入力を、このObsidianセカンドブレインに取り込むための計画。

## 本来の目的

ジャーナルへの音声入力を、Obsidian（このVault）できちんと管理できるようにすること。
自動化そのものはあくまで手段であり、目的ではない。

## 採用する運用方法（確定）

**iPhoneのキーボードのマイク機能で、このチャット（Claude Code）に直接話しかける方式**を
正式な運用フローとする。

- 流れ: 音声入力 → キーボードが自動でテキスト化 → チャットに送信
  → Claude Codeが内容を `00-Journal` のデイリーノートに整形し、
  必要に応じて `01-Projects` / `02-Areas` / `03-Resources` のノートも
  作成・更新する。
- 動作確認済み（2026-09-29）で、安定して機能している。
- セットアップ不要・追加の障害点（トークン、ネットワーク、ショートカットの
  内部エラーなど）がなく、目的（音声→Obsidian管理）を即座に満たせる。

## 保留: iOS Shortcuts自動送信

iPhoneの「ジャーナル」アプリの音声記録を、iOS Shortcuts経由でGitHub Contents API に
直接送信し、`vault/99-Inbox/` に自動で取り込む案は**保留**とする。

- 状況（2026-10-03時点）:
  - ✅ GitHub Personal Access Token発行、Shortcutsからの認証・接続
  - ✅ 本文・日付をファイルに正しく記録
  - ✅ ファイル名のURL変数解決の不具合を解消（置き換えアクションの出力を
    一度テキストアクションでURL文字列として組み立て、それだけを
    「URLの内容を取得」のURL欄に渡す方式で解決）し、実際にGitHubへの
    コミットに一度成功
  - ❌ 直後から毎回「ネットワーク接続が切れました」エラーが発生し、
    実行できない状態（Wi-Fi/モバイル通信の切り替え、再起動、低データ
    モード確認などを行ったが未解決。設定自体の問題ではなく、環境側の
    一時的な要因の可能性が高い）
- この案は、本来の目的（ジャーナル→Obsidian管理）にとって必須ではないため、
  上記の「保留」状態のまま優先度を下げる。時間に余裕があるときに再検証する。

## メモアプリ版セカンドブレイン

- 入力元: iPadの「メモ」アプリの音声記録
- 状況: 未着手。ジャーナル版の運用が安定してから着手する。

## 進め方

1. ジャーナル版は「キーボードのマイク機能でチャットに話しかける」方式で運用を開始する（完了）。
2. iOS Shortcuts自動送信は保留。必要になれば再度取り組む。
3. ジャーナル版の運用が安定したら、メモアプリ版の設計に着手する。
