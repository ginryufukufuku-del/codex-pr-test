# Slide2Video

スライド（タイトル・本文・画像・表示秒数）を動画(WebM)に変換するブラウザアプリです。

## 使い方

`index.html` をブラウザで開きます（ビルド不要）。

1. スライドを追加し、タイトル・本文・画像・秒数を入力（字幕は改行で区切ると表示時間を等分して切り替わります。ナレーションは音声ファイルの読み込み、またはマイク録音。音声が長ければ表示時間が自動で延びます）
2. 「▶ プレビュー」で確認
3. 「⏺ 動画を書き出す」でWebMを生成してダウンロード

## 仕組み

Canvasにスライドを描画し、`captureStream` と `MediaRecorder` で録画します。
